# Notion-mind 사용 가이드

Notion-mind는 노션 워크스페이스에 쌓인 페이지와 데이터베이스를 하나의 노드 그래프로 펼쳐 보여주는 웹 도구입니다. 노션 안에서는 페이지가 트리(폴더) 구조로만 보이지만, 실제 워크스페이스는 데이터베이스 소속, 하위 페이지, 관계형(relation) 속성이 얽힌 그물 구조입니다. 이 가이드는 처음 접속해서 그래프를 읽고 다루는 방법까지를 순서대로 설명합니다.

## 1. 시작하기: 노션 계정으로 로그인

Notion-mind에는 별도의 회원가입이 없습니다. 첫 화면에서 "Notion으로 계속하기"를 누르면 노션의 인증 화면으로 이동합니다.

1. 노션 계정으로 로그인합니다. 이미 브라우저에 노션이 로그인되어 있으면 이 단계는 건너뜁니다.
2. 워크스페이스를 고릅니다. 여러 워크스페이스에 속해 있다면 그래프로 볼 워크스페이스를 하나 선택합니다.
3. 접근을 허용할 페이지를 고릅니다. "모든 페이지"를 고르면 워크스페이스 전체가, 특정 페이지만 고르면 그 페이지와 하위 페이지만 그래프에 나타납니다.
4. "접근 허용"을 누르면 Notion-mind로 돌아오고, 그래프 화면이 열립니다.

Notion-mind가 받는 권한은 읽기 전용입니다. 페이지 내용을 바꾸거나 새 페이지를 만들지 않습니다. 접근 권한은 노션 설정의 "연결된 앱"에서 언제든지 회수할 수 있습니다.

## 2. 첫 화면 읽기

로그인 직후 "워크스페이스를 읽는 중" 안내가 뜨고, 페이지가 100개 단위로 도착할 때마다 그래프가 실시간으로 자랍니다. 페이지가 많은 워크스페이스는 전체가 도착하기까지 수십 초가 걸릴 수 있으며, 그동안 상단에 "페이지 N개 읽는 중" 표시가 보입니다.

그래프의 구성 요소는 세 가지입니다.

- **노드(블록)**: 페이지 하나가 흰 블록 하나입니다. 데이터베이스는 조금 더 진한 회색 블록에 디스크 아이콘이 붙습니다. 제목이 길면 두 줄로 줄여 보이고, 마우스를 올리면 전체 제목이 펼쳐집니다.
- **실선**: 소속 관계입니다. 데이터베이스와 그 안의 페이지를 잇는 선은 검정, 페이지 안에 들어 있는 하위 페이지나 데이터베이스를 잇는 선은 회색입니다.
- **점선**: 데이터베이스의 관계형(relation) 속성으로 연결된 페이지끼리 잇습니다. 트리 구조에서는 보이지 않던 "가로 연결"이 이 점선입니다.

배치는 물리 시뮬레이션이 정합니다. 연결이 많은 데이터베이스는 자식 페이지들이 동심원 형태로 둘러싸고, 관계가 없는 페이지는 바깥으로 밀려납니다. 처음 몇 초간 노드가 출렁이다가 자리를 잡는 것이 정상입니다.

## 3. 화면 조작

### 이동과 확대, 축소

- 빈 곳을 끌면 화면이 움직입니다.
- 마우스 휠 또는 트랙패드 핀치로 확대, 축소합니다. 우하단 컨트롤의 +, − 버튼과 세로 슬라이더로도 조절할 수 있고, 맨 아래 버튼을 누르면 기본 배율(100%)로 돌아갑니다.
- 화면을 많이 축소하면 블록이 작은 정사각형으로 바뀌어 전체 모양만 보입니다. 다시 확대하면 제목이 돌아옵니다.
- 마지막 화면 위치와 배율은 브라우저에 기억되어 다음 접속 때 같은 자리에서 시작합니다.

### 마우스 올리기(호버)

노드 위에 마우스를 올리면 그 노드와 직접 연결된 이웃만 선명하게 남고 나머지는 흐려집니다. 연결선은 파란색으로 강조됩니다. 특정 페이지가 어디에 얽혀 있는지 한눈에 볼 때 씁니다.

### 노드 끌기

노드를 끌어 옮길 수 있습니다. 이웃 노드들이 스프링처럼 딸려오고, 놓으면 출렁이며 다시 정착합니다. 원하는 배치가 있으면 아래 "핀 고정"으로 그 자리에 박아 둘 수 있습니다.

### 우클릭 메뉴: 숨기기와 핀 고정

노드를 우클릭하면 메뉴가 뜹니다.

- **숨기기**: 그 노드를 그래프에서 치웁니다. 관심 없는 페이지나 잡동사니를 걷어낼 때 씁니다. 숨긴 노드가 있으면 화면 하단에 "숨긴 노드 N개, 모두 표시"와 "숨긴 목록 보기" 버튼이 나타납니다. 목록에서 항목별로 다시 표시할 수 있습니다.
- **핀 고정**: 물리 시뮬레이션이 그 노드를 더 이상 움직이지 않습니다. 끌어다 놓은 자리에 그대로 남습니다. 다시 우클릭해 "핀 해제"하면 풀립니다.

Free 요금제에서는 숨김과 핀이 현재 브라우저 세션에만 남고, 새로고침하면 초기화됩니다. Pro 요금제에서는 서버에 저장되어 다음 접속과 다른 기기에서도 그대로 복원됩니다.

## 4. 노드 상세 패널

노드를 클릭하면 오른쪽에서 상세 패널이 열립니다. 패널이 열려 있어도 그래프는 계속 조작할 수 있습니다.

- 소속(어느 데이터베이스나 페이지 안에 있는지)
- 데이터베이스 속성 값
- 마지막 수정 시각
- 관계형으로 연결된 페이지, 하위 페이지 목록. 각 항목을 누르면 그래프의 해당 노드로 화면이 이동합니다.
- 본문 미리보기(처음 24줄)
- "노션에서 열기" 버튼

닫으려면 X 버튼, ESC 키, 또는 그래프 빈 곳을 클릭합니다.

## 5. 검색과 설정

좌상단 검색창에 제목 일부를 입력하면 일치하는 노드로 화면이 이동합니다.

좌상단 "Notion-mind" 로고 박스는 설정 버튼입니다. 누르면 설정 패널이 열리고 다음을 할 수 있습니다.

- 연결된 워크스페이스 이름 확인
- 요금제 확인과 변경(Pro 구독, 구독 관리)
- 연결된 페이지 변경: 노션 인증 화면으로 돌아가 접근 허용 페이지를 다시 고릅니다.
- 수동 동기화: 노션에서 페이지를 추가하거나 옮긴 뒤 그래프를 다시 읽습니다. 마지막 동기화 시각이 표시됩니다.
- 로그아웃

좌하단 스위치로 라이트, 다크 모드를 바꿉니다. 처음에는 시스템 설정을 따릅니다.

## 6. 요금제

- **Free**: 최근 수정순으로 페이지 1,000개까지 그래프에 표시합니다. 그래프 기능은 전부 쓸 수 있고, 화면 하단에 광고가 표시됩니다. 우상단 페이지 수 박스에서 현재 개수와 상한을 볼 수 있습니다.
- **Pro**: 페이지 수 제한이 사실상 없고(20,000개), 숨김과 핀이 영구 저장되며, 광고가 사라집니다. 월 $7 또는 연 $48이며 결제 후 14일 이내에는 전액 환불됩니다. 자세한 내용은 [요금제](/pricing) 화면과 [환불정책](/refund)을 참고하세요.

## 7. 연결 해제와 데이터

Notion-mind는 워크스페이스 내용을 서버에 저장하지 않습니다. 그래프에 필요한 제목, 속성, 관계 정보를 노션에서 읽어 브라우저로 바로 전달할 뿐입니다. 로그아웃하면 브라우저에 있던 접근 토큰이 삭제되고, 노션 설정의 "연결된 앱"에서 Notion-mind를 지우면 이후 접근이 완전히 차단됩니다. 자세한 내용은 [개인정보 처리방침](/privacy)에 있습니다.

## 8. 문제가 생겼을 때

- **그래프에 페이지가 몇 개 안 보인다**: 노션 인증 화면에서 일부 페이지만 허용했을 가능성이 큽니다. 설정 패널의 "연결된 페이지 변경"에서 다시 고르세요.
- **최근에 만든 페이지가 없다**: 설정 패널에서 "수동 동기화"를 누르세요. 노션 API 특성상 방금 만든 페이지는 몇 초 뒤에 검색에 잡힙니다.
- **"페이지 열기 실패" 또는 로그인 오류**: 브라우저 쿠키가 차단되어 있으면 로그인 상태를 유지할 수 없습니다. notion-mind.com의 쿠키를 허용한 뒤 다시 시도하세요.
- **화면이 멈춘 것처럼 보인다**: 페이지가 수천 개인 워크스페이스는 첫 배치에 시간이 걸립니다. 상단 진행 표시가 사라질 때까지 기다려 주세요.
