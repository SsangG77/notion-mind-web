# 노션 vs 옵시디언, 그래프뷰 차이

노션과 옵시디언은 노트 앱 중에서 가장 자주 비교되는 짝이고, 비교는 대개 화면 하나에서 끝납니다. 그래프뷰입니다. 옵시디언에는 있고 노션에는 없습니다. 다만 다른 것도 전부 다르므로, 그래프뷰가 정말 나에게 중요한 차이인지 정하기 전에 전체 목록을 한 번 볼 만합니다.

## 한눈에 보기

| | 노션 | 옵시디언 |
| --- | --- | --- |
| 노트가 있는 곳 | 노션 서버. 앱이나 브라우저로 엽니다 | 내 기기 폴더 안의 마크다운 파일 |
| 오프라인 | 오프라인 사용으로 지정한 페이지만, 데스크톱과 모바일 앱에서 | 전부, 항상. 파일이 내 기기에 있습니다 |
| 구조 | 페이지 안의 페이지, 속성이 있는 데이터베이스 | 파일과 폴더, `[[위키링크]]` 로 연결 |
| 데이터베이스 | 기본 기능. 표, 보드, 타임라인, 캘린더, 목록, 갤러리, 차트 | Bases. 노트 속성으로 표 모양 보기를 만드는 코어 플러그인 |
| 함께 쓰기 | 동시 편집, 댓글, 페이지별 권한 | 혼자 쓰는 용도. 공동 편집은 추가 기능이 필요합니다 |
| 확장 | API 를 통한 연동 | 앱 자체를 바꾸는 커뮤니티 플러그인과 테마 |
| 그래프뷰 | 없음 | 기본 제공. 보관함 전체 또는 노트 하나 기준 |

## 노트가 어디에 있나

나머지 차이가 전부 여기서 나옵니다. 옵시디언 보관함(vault)은 평범한 마크다운 파일이 든 폴더입니다. 어떤 텍스트 편집기로도 열리고, 백업은 원하는 방식으로 하면 되고, 옵시디언이 내일 사라져도 파일은 그대로 읽힙니다. 기기 간 동기화는 고르면 됩니다. 옵시디언이 파는 동기화 서비스를 써도 되고, 이미 쓰는 파일 동기화에 폴더를 올려도 됩니다.

노션은 워크스페이스를 노션 서버에 둡니다. 그래서 페이지 공유가 클릭 한 번이고 두 사람이 같은 문단을 동시에 고칠 수 있습니다. 대신 노트가 내가 쥔 파일이 아닙니다. 노션에 오프라인 모드가 생겼지만 페이지 단위입니다. 데스크톱이나 모바일 앱에서 페이지를 오프라인 사용으로 지정해야 하고, 그 지정은 기기마다 따로입니다.

## 데이터베이스

노션을 못 떠나는 이유는 대개 데이터베이스입니다. 줄 하나가 페이지 하나이고, 속성은 날짜, 선택, 사람, 수식이 될 수 있고, 관계형 속성이 한 데이터베이스의 줄을 다른 데이터베이스의 줄에 잇습니다. 같은 데이터를 복사 없이 표, 보드, 캘린더, 타임라인으로 바꿔 봅니다.

옵시디언은 Bases 로 일부를 따라왔습니다. 노트 맨 위의 속성을 읽어 노트를 필터되는 표나 카드로 보여 주는 코어 플러그인입니다. 독서 목록이나 프로젝트 색인에는 충분합니다. 관계형 데이터베이스는 아닙니다. 관계형 속성을 타고 건너가 세는 롤업 같은 것은 없습니다.

## 함께 쓰기

노션은 팀을 위해 만들어졌습니다. 댓글, 멘션, 페이지별 권한, 공유 사이드바가 기본입니다. 옵시디언은 한 사람의 노트를 위해 만들어졌습니다. 공유 보관함이 있고 커뮤니티 플러그인이 동시 편집을 더해 주지만, 앱의 본래 쓰임은 아닙니다.

## 링크, 백링크, 그래프

두 앱 모두 노트끼리 링크할 수 있고 백링크를 보여 줍니다. 차이는 그 링크로 그다음에 무엇을 하느냐입니다.

옵시디언은 그립니다. 그래프뷰는 노트를 점으로, 링크를 선으로 그리는 코어 플러그인입니다. 검색어로 거르고, 노트 묶음에 색을 입히고, 링크가 하나도 없는 노트를 보이거나 숨기고, 지금 읽는 노트 주변만 보여 주는 로컬 그래프를 열 수 있습니다. 관리할 것이 없습니다. 링크를 쓰면 그림이 바뀝니다.

노션에도 연결은 그만큼 많습니다. 페이지는 상위 페이지 안에 있고, 줄은 데이터베이스에 속하고, 관계형 속성은 다른 곳의 줄을 가리키고, 멘션은 두 페이지를 잇습니다. 그런데 데이터베이스 보기는 전부 데이터베이스 하나를 줄 단위로 보여 주고, 백링크는 한 페이지씩만 나옵니다. 전체 모양을 보여 주는 화면이 없습니다. 제목의 "차이"가 이것입니다.

## 어느 쪽을 고를까

- **옵시디언**: 파일을 내가 갖는 것, 완전한 오프라인, 노트의 모양을 보는 것이 가장 중요하고 노트가 주로 나를 위한 것일 때
- **노션**: 데이터베이스가 필요하거나, 다른 사람과 일을 나누거나, 문서와 구조화된 데이터를 한곳에 두고 싶을 때
- **둘 다**: 깔끔하게 나눌 수 있을 때. 예를 들어 팀 프로젝트는 노션, 혼자 하는 생각은 옵시디언. 같은 노트가 양쪽에 다 있어야 하는 순간부터 안 굴러갑니다

## 노션에 남았는데 그래프가 아쉽다면

가장 흔한 결말입니다. 데이터베이스와 공유 때문에 노션을 고르고, 딱 하나가 아쉽습니다. 화면 하나 때문에 전부 옵시디언으로 옮기는 건 손해입니다. 관계형, 롤업, 데이터베이스 보기는 노션 워크스페이스에서 온전히 안 넘어가는 부분입니다.

Notion-mind 는 옮기지 않고 그 화면 하나를 채웁니다. 워크스페이스에 이미 있는 세 가지 연결(데이터베이스 소속, 하위 페이지, 관계형 속성)을 읽어 그래프로 그립니다. 페이지와 데이터베이스는 노드, 연결은 선입니다. 노드에 마우스를 올리면 엮이지 않은 것은 전부 흐려져서 옵시디언의 로컬 그래프처럼 보이고, 필터 하나로 관계형이 하나도 안 걸린 페이지만 남길 수 있습니다.
