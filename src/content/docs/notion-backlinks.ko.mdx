# 노션 백링크, 어디서 보고 왜 안 보이나

백링크는 **지금 페이지를 가리키는 다른 페이지들의 목록**입니다. 페이지 맨 위 제목 근처에 "백링크 N개"라는 작은 표시로 떠 있고, 누르면 목록이 열립니다. 데이터베이스 안의 페이지면 속성 칸에 같이 나옵니다. 따로 켜는 게 아니라 다른 페이지에서 이 페이지를 링크하는 순간 자동으로 생깁니다.

## 백링크가 생기는 경우

셋이고, 전부 일부러 거는 링크입니다.

- **@멘션.** 글 안에서 `@` 를 치고 페이지 이름을 고릅니다
- **페이지 링크 블록.** `/` 메뉴에서 페이지 링크(영문 화면의 Link to page)를 고르고 페이지를 정합니다
- **붙여 넣은 페이지 주소**를 멘션이나 링크로 바꾼 것

`[[` 를 치고 페이지 이름을 쓰기 시작해도 같은 선택지가 나옵니다. 있는 페이지에 링크하거나 새 페이지를 만듭니다.

## 백링크가 안 생기는 경우

헷갈리는 일은 대부분 여기서 나옵니다.

- **하위 페이지인 것.** 다른 페이지 안에 든 페이지는 링크가 아니라 소속입니다. 상위 페이지에 하위 페이지가 백링크로 뜨지 않습니다
- **같은 데이터베이스에 있는 것.** 한 데이터베이스의 줄들은 그것만으로 서로 링크된 것이 아닙니다
- **관계형 속성.** 관계형은 백링크가 아니라 속성입니다. 그 연결은 속성 열에 나오고 백링크 목록에는 안 나옵니다

## 안 보이는 이유

백링크가 있을 줄 알았는데 없다면 대개 이 중 하나입니다.

1. **아직 아무도 링크하지 않았음.** 소속이나 관계형으로 이어진 것이고, 그건 위에 적은 대로 안 잡힙니다
2. **그 페이지에서 백링크를 숨겼음.** 페이지의 `•••` 메뉴에 페이지 사용자 지정 항목(영문 화면의 Customize page)이 있고, 거기서 백링크를 펼쳐서 보일지, 팝오버에 넣을지, 끌지 정합니다. 링크된 걸 아는 페이지인데 표시가 없으면 여기를 봅니다
3. **권한.** 내가 접근할 수 있는 페이지에서 걸린 백링크만 보입니다. 다른 사람의 비공개 페이지에서 건 링크는 내 목록에 안 나옵니다
4. **링크가 지워졌음.** 백링크는 실시간입니다. 멘션을 지우면 백링크도 같이 사라집니다

## 백링크를 잘 쓰는 습관

- **제목을 타이핑하지 말고 멘션하기.** "3분기 계획 참고"라고 쓰면 아무것도 안 생깁니다. `@3분기 계획` 이라고 쓰면 양쪽으로 링크가 생깁니다
- **회의록에서 프로젝트를 멘션하기.** 프로젝트 페이지에 그 프로젝트를 다룬 회의가 전부 모입니다. 누가 따로 정리하지 않아도 됩니다
- **페이지를 지우기 전에 목록 열어 보기.** 지우고 나면 허공을 가리키게 될 페이지가 무엇인지 나옵니다

## 백링크와 관계형, 언제 무엇을

| | 백링크 | 관계형 속성 |
| --- | --- | --- |
| 만드는 방법 | 글 안에서 멘션하거나 링크 | 데이터베이스 속성에서 페이지 선택 |
| 이을 수 있는 대상 | 아무 페이지 둘 | 데이터베이스의 줄 |
| 필터와 정렬 | 안 됨 | 됨 |
| 롤업에 쓸 수 있나 | 아니요 | 예 |
| 상대 쪽에 표시 | 항상 | 양방향을 켰을 때만 |

글 속에서 지나가며 언급할 때는 멘션을 씁니다. 연결이 구조의 일부이고 그걸로 거르거나 세고 싶을 때는 관계형을 씁니다. 그쪽은 [관계형과 롤업](/ko/blog/notion-relation-property)에 적었습니다.

## 한계

백링크는 잘 작동합니다. 한계는 **한 번에 한 페이지 기준**이라는 것입니다. 이 페이지로 오는 것만 보여 주고, 거기서 또 어디로 이어지는지, 전체가 어떤 모양인지는 페이지를 하나씩 열어 가며 머리로 이어 붙여야 합니다. 그리고 소속과 관계형은 애초에 그 목록 밖이라, 백링크 창은 한 페이지에 대해서도 절반의 답입니다.

Notion-mind 는 구조를 이루는 연결을 한 화면에 그립니다. 하위 페이지와 데이터베이스 소속은 실선, 관계형 속성은 점선입니다. 노드에 마우스를 올리면 그 페이지로 들어오고 나가는 연결만 남고 나머지는 흐려집니다. 백링크 창이 답하는 것과 같은 질문을 지도로 읽는 셈입니다.
