# 노션 관계형 속성, 롤업과 뭐가 다른가요?

관계형은 페이지를 다른 페이지에 **잇는** 속성이고, 롤업은 그 연결을 타고 건너가 상대 페이지의 값을 **가져와 세는** 속성입니다. 그래서 롤업은 관계형이 먼저 있어야 만들 수 있습니다. 둘을 같은 것으로 보고 찾으면 롤업 메뉴에서 연결할 대상을 못 찾아 막힙니다.

## 관계형: 줄과 줄을 잇는 링크

관계형은 값이 다른 데이터베이스(또는 같은 데이터베이스)의 페이지 목록인 속성입니다. 작업 데이터베이스에 "프로젝트"라는 관계형을 두면, 각 작업이 속한 프로젝트 페이지가 그 칸에 들어갑니다. 칸을 누르고, 검색하고, 페이지를 고르면 두 줄이 이어집니다.

만드는 순서는 이렇습니다.

1. 데이터베이스를 열고 새 속성을 추가합니다
2. 유형으로 **관계형**을 고릅니다
3. 이을 데이터베이스를 고릅니다
4. 페이지 1개로 제한할지, 제한 없이 둘지 정합니다
5. 양쪽에서 다 보이게 하려면 상대 데이터베이스에 표시하는 토글(영문 화면의 Show on …)을 켭니다

## 한 방향과 양방향

관계형은 기본이 한 방향입니다. 작업에 프로젝트를 넣어도 프로젝트 쪽에는 아무것도 안 생깁니다. 상대 데이터베이스에 표시하는 토글을 켜면 양방향이 됩니다. 상대 데이터베이스에 짝이 되는 속성이 생기고, 그때부터 어느 쪽에서 고쳐도 같이 바뀝니다.

대개는 양방향이 맞습니다. 예외가 하나 있습니다. 상대 데이터베이스를 다른 사람과 공유하고 있고 거기에 새 열이 보이면 안 될 때는 한 방향으로 둡니다.

관계형은 자기 데이터베이스를 가리킬 수도 있습니다. 작업에 하위 작업을 달거나 노트에 "관련 노트"를 다는 방식이 그것입니다.

## 롤업: 관계형을 건너가 가져온 값

롤업은 세 가지를 골라야 합니다.

1. **어느 관계형**을 따라갈지
2. 건너편 페이지의 **어느 속성**을 읽을지
3. 결과를 **어떻게 계산**할지

프로젝트 데이터베이스가 작업과 양방향 관계형으로 이어져 있으면, 롤업이 작업을 따라가 상태 속성을 읽고 완료된 비율을 보여 줄 수 있습니다. 관계형 하나에 롤업 여러 개를 걸 수 있습니다. 작업 수, 가장 늦은 마감일, 예상 시간 열의 합계 같은 식입니다.

계산은 몇 묶음으로 나뉩니다.

- 값을 있는 그대로, 또는 중복 없이 **표시**
- 전체, 고유한 값, 빈 값과 빈 값이 아닌 것을 개수나 비율로 **세기**
- **숫자**: 합계, 평균, 중앙값, 최소, 최대, 범위
- **날짜**: 가장 이른 날짜, 가장 늦은 날짜, 날짜 범위

## 나란히 놓고 보기

| | 관계형 | 롤업 |
| --- | --- | --- |
| 담는 것 | 페이지로 가는 링크 | 그 페이지들에서 계산한 값 |
| 상대가 필요한가 | 아니요 | 예, 관계형이 먼저 있어야 함 |
| 칸에서 고칠 수 있나 | 예, 페이지를 넣고 뺍니다 | 아니요, 계산된 값입니다 |
| 흔한 쓰임 | "이 작업은 저 프로젝트 것" | "이 프로젝트는 작업 12개, 75% 완료" |
| 어느 페이지와 엮였는지 보이나 | 예 | 원본 표시일 때만 |

## 자주 막히는 지점

- **롤업 메뉴가 비어 있음.** 그 데이터베이스에 관계형이 아직 없습니다. 관계형부터 만듭니다
- **상대 쪽에 연결이 안 보임.** 관계형이 한 방향입니다. 속성을 편집해서 상대 데이터베이스에 표시하는 토글을 켭니다
- **숫자를 원했는데 롤업에 목록이 나옴.** 계산이 아직 원본 표시로 되어 있습니다. 개수나 합계로 바꿉니다
- **페이지를 하나만 고를 수 있음.** 관계형이 1개로 제한되어 있습니다. 속성 설정에서 바꿉니다

## 둘 다 못 보여 주는 것

관계형 열은 줄 하나의 연결을 보여 줍니다. 롤업은 그 연결을 숫자로 접습니다. 둘 다 **연결 전체의 모양**은 보여 주지 않습니다. 데이터베이스 셋이 서로를 가리키기 시작하면(작업에서 프로젝트로, 프로젝트에서 고객으로, 회의록에서 둘 다로) 그 그물은 머릿속에만 있고, 어떤 페이지가 아무 데도 안 엮였다는 건 열을 내려가며 빈 칸을 찾아야 압니다.

Notion-mind 는 그 관계형을 노드 사이의 점선으로 그립니다. 한 방향이든 양방향이든 선은 하나이고, 어느 데이터베이스에서 출발했든 한 화면에 모입니다. 데이터베이스 소속과 하위 페이지는 실선으로 같이 그려져서, 관계형이 페이지 구조 위에서 어디를 가로지르는지가 보입니다.
