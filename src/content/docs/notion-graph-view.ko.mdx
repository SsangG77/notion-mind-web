# 노션에 그래프뷰가 있나요?

없습니다. 노션에는 옵시디언 같은 그래프뷰가 없고, 그 기능을 더해 주는 공식 플러그인도 없습니다. 데이터베이스를 보여 주는 방식은 표, 보드, 타임라인, 캘린더, 목록, 갤러리, 차트뿐이고 전부 한 번에 하나의 데이터베이스만 줄 단위로 보여 줍니다. 페이지끼리 어떻게 엮여 있는지를 한 화면에 펼쳐 주는 보기는 없습니다.

그래서 사람들은 외부 도구를 씁니다. 다만 대부분은 직접 그리는 도구라, 그린 그림이 노션 안의 실제 연결과 따로 놉니다. 페이지를 하나 추가하면 그림은 그만큼 낡습니다.

Notion-mind 는 그리지 않습니다. 워크스페이스에 이미 있는 연결을 그대로 읽어 그립니다.

- 어느 페이지가 어느 데이터베이스에 속하는지
- 어느 페이지가 어느 페이지 안에 들어 있는지
- 관계형 속성이 어디를 가리키는지

이 셋이 각각 선이 되고, 페이지와 데이터베이스가 노드가 됩니다. 옵시디언이 노트 사이의 링크를 그리는 것과 같은 방식인데, 링크 대신 노션의 소속과 관계형을 씁니다. 열 때마다 워크스페이스에서 다시 만들기 때문에 따로 관리할 것이 없고 낡지도 않습니다.

마우스를 올리면 연결 안 된 노드가 흐려져서 한 페이지의 주변만 볼 수 있고, 관계형이 한 번도 안 닿은 페이지만 남기는 필터도 있습니다. 한 번 쓰고 잃어버린 메모를 찾는 데 쓰는 기능입니다.
