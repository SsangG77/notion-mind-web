# 노션에 그래프뷰가 있나요?

없습니다. 노션에는 옵시디언 같은 그래프뷰가 없습니다. 데이터베이스를 보여 주는 방식은 표, 보드, 타임라인, 캘린더, 목록, 갤러리, 차트이고 전부 한 번에 하나의 데이터베이스만 줄 단위로 보여 줍니다. 페이지끼리 어떻게 엮여 있는지를 한 화면에 펼쳐 주는 보기는 노션 안에 없습니다.

## 그래프뷰가 무엇인가

그래프뷰는 노트 하나를 점(노드)으로, 두 노트 사이의 링크를 선으로 그립니다. 목록으로는 답이 안 나오는 질문에 답합니다. 어느 노트가 중심인지, 어느 노트가 외따로 있는지, 어느 두 주제가 페이지 하나로 이어져 있는지. 옵시디언이 널리 알렸고, 옵시디언에서 넘어온 사람이 가장 먼저 찾는 기능입니다.

## 노션이 대신 주는 것

노션에서 연결을 보는 방법은 네 가지이고, 각각 한 조각씩 보여 줍니다.

- **사이드바와 이동 경로**: 어느 페이지가 어느 페이지 안에 있는지. 페이지 트리이고, 트리만 보입니다
- **백링크**: 지금 페이지를 멘션하거나 링크한 페이지 목록. 한 번에 한 페이지 기준이고 관계형과 소속은 빠집니다. 어디에 뜨고 왜 안 보이는지는 [노션 백링크](/ko/blog/notion-backlinks)에 있습니다
- **관계형 속성**: 한 줄이 다른 데이터베이스의 어느 줄과 이어졌는지를 열 하나로. 작동 방식은 [관계형과 롤업](/ko/blog/notion-relation-property)에 있습니다
- **데이터베이스 보기**: 데이터베이스 하나의 줄을 표, 보드, 타임라인으로

넷 다 정확합니다. 그림은 아닙니다. 프로젝트 페이지, 그걸 멘션한 회의록, 거기에 관계형으로 걸린 작업이 어떻게 맞물려 있는지 알려면 하나씩 열어 보고 머릿속에서 이어 붙여야 합니다.

## 그래도 찾는 이유

페이지 쉰 개짜리 워크스페이스에는 그래프가 필요 없습니다. 천 개가 되면 필요해지고, 이유는 셋입니다.

1. **잊어버린 것 찾기.** 아무 데서도 링크하지 않은 페이지는 이름을 기억하지 못하면 어느 목록에도 안 나옵니다
2. **뭉친 모양 보기.** 한 주제의 노트가 한 덩어리인지, 서로 안 이어진 세 덩어리인지는 표에서 안 보입니다
3. **길 따라가기.** "이 노트가 어쩌다 저 프로젝트와 이어졌지?"는 여러 단계를 건너는 질문인데, 백링크는 한 단계씩만 답합니다

## 우회 방법과 각각의 한계

**손으로 그리기.** 화이트보드 도구를 노션 페이지에 임베드하면 그림은 생깁니다. 다만 그 그림은 노션 안의 링크와 따로 놉니다. 페이지를 하나 추가하면 그림은 이미 낡았습니다.

**다른 앱으로 내보내기.** 노션은 페이지를 마크다운으로 내보낼 수 있고, 옵시디언이 그 결과를 엽니다. 페이지 링크는 일부 살아남지만 관계형 속성과 데이터베이스 구조는 온전히 안 넘어가고, 내보낸 것은 그 순간부터 낡기 시작하는 사본입니다.

**워크스페이스를 읽는 도구 연결하기.** 노션 API 는 페이지, 데이터베이스, 관계형 속성을 내어 주므로 외부 도구가 실제 연결을 읽어 그릴 수 있습니다. 워크스페이스에서 만든 그림이라 워크스페이스와 어긋나지 않습니다.

## Notion-mind 가 그리는 것

Notion-mind 는 세 번째 종류입니다. 워크스페이스가 이미 기록하고 있는 세 가지를 읽습니다.

- 각 페이지가 어느 데이터베이스에 속하는지
- 어느 페이지가 어느 페이지 안에 있는지
- 각 관계형 속성이 어디를 가리키는지

각각이 선이 되고, 페이지와 데이터베이스는 노드가 됩니다. 소속과 하위 페이지는 실선, 관계형은 점선이라 구조와 가로지르는 연결이 한눈에 갈립니다. 열 때마다 워크스페이스에서 다시 만들므로 관리할 것이 없습니다.

노드에 마우스를 올리면 연결되지 않은 것은 전부 흐려집니다. 옵시디언의 로컬 그래프에 가장 가까운 동작입니다. 노드를 누르면 속성, 관계형 연결, 노션으로 바로 가는 링크가 나옵니다. 필터 하나로 관계형이 하나도 안 걸린 페이지만 남길 수 있습니다.

연결하기 전에 어떻게 움직이는지 보고 싶으면 홈 화면에 로그인 없이 만져 보는 예시 그래프가 있습니다. 이 화면 말고 두 앱이 어떻게 다른지는 [노션 vs 옵시디언](/ko/blog/notion-vs-obsidian-graph-view)에 있습니다.
