# 노션에 마인드맵 기능이 있나요?

노션 자체에는 마인드맵 뷰도 그래프 뷰도 없습니다. 내 워크스페이스를 노션 마인드맵처럼 펼치면 이렇게 보입니다.

## 직접 그리는 것보다 나은 점

- **그릴 필요가 없습니다.** 워크스페이스에 이미 있는 연결(데이터베이스 소속, 하위 페이지, 관계형 속성)을 읽어서 자동으로 배치합니다
- **낡지 않습니다.** 열 때마다 워크스페이스에서 다시 만듭니다. 손으로 그린 그림은 페이지를 하나 추가한 순간부터 낡습니다
- **워크스페이스 전체가 한 화면에.** 노션에서는 한 번에 하나씩만 보이던 연결이 나란히 놓입니다
- **한 페이지만 따라가기.** 마우스를 올리면 연결 안 된 것이 흐려지고, 누르면 속성과 관계형 연결, 노션으로 바로 가는 링크가 열립니다
- **잃어버린 것 찾기.** 필터 하나로 관계형이 한 번도 안 닿은 페이지만 남습니다. 한 번 쓰고 다시 못 찾은 메모들입니다

## 워크스페이스 연결하기

구글로 로그인한 뒤 노션 워크스페이스를 연결합니다. 따로 만들 계정은 없습니다. 노션 동의 화면에서 공유할 페이지를 직접 고르니 워크스페이스 한쪽 구석으로 먼저 시험해 볼 수 있습니다. 제목과 속성, 연결 정보를 노션에서 읽어 브라우저에서 그릴 뿐 내용을 서버에 저장하지 않습니다. 무료는 페이지 1,000개까지입니다.
