# 노션에서 마인드맵 만드는 법

노션에는 마인드맵 기능이 없어서, 만드는 방법은 둘 중 하나입니다. **토글로 쌓거나, 그림 도구를 임베드하거나.** 5분이면 되는 쪽부터, 그다음 진짜 지도 모양이 나오는 쪽, 마지막으로 고르는 기준 순서로 적습니다.

## 1. 토글로 만들기 (노션 안에서 끝남)

1. 빈 페이지에서 `>` 를 치고 한 칸 띄워 토글 블록을 만들고, 중심 생각을 적습니다
2. 토글을 열고 그 안에 큰 가지를 토글로 하나씩 넣습니다
3. 가지 안에 다시 토글을 넣어 깊이를 늘립니다
4. 토글 왼쪽 손잡이를 끌어 가지를 다른 곳으로 옮깁니다. 안에 든 것이 전부 같이 움직입니다

토글 지도를 쓰기 편하게 만드는 요령이 몇 가지 있습니다.

- **첫 단계는 토글 제목으로.** `/` 메뉴에서 토글 제목 블록(영문 화면의 Toggle heading)을 고르고 크기를 정합니다. 가지가 안의 내용과 구분돼 보입니다
- **열로 가지를 나란히 놓기.** 토글 하나를 다른 토글의 오른쪽 끝으로 끌어 세로선이 나타나면 놓습니다. 열 서너 개면 목록보다 지도에 가까워집니다
- **가지를 실제 페이지에 링크하기.** 토글 안에서 `@` 를 치고 페이지 이름을 고릅니다. 가지가 자세한 내용이 있는 페이지를 가리키게 되고, 그 페이지에는 백링크가 생깁니다
- **안 쓰는 가지는 접어 두기.** 토글 스무 개가 다 열린 지도는 다시 개요입니다

장점은 전부 평범한 노션 내용이라는 것입니다. 검색되고, 링크되고, 휴대폰에서도 고칠 수 있습니다. 한계는 모양입니다. 위에서 아래로 읽히고, 반대편에 있는 두 가지 사이에 선을 그을 수 없습니다.

## 2. 그림 도구를 임베드하기 (진짜 지도 모양)

1. Miro 나 Excalidraw 에서 마인드맵을 그립니다. 둘 다 노션이 임베드를 지원하는 앱입니다
2. 보드의 공유 링크를 복사합니다
3. 노션 페이지에 붙여 넣습니다. 노션이 임베드할 수 있는 주소를 알아보고 선택지를 띄웁니다
4. 임베드를 고릅니다. 페이지 안에서 그 보드가 그대로 보이고, 그 자리에서 계속 편집됩니다
5. 임베드 모서리를 끌어 자리를 넉넉히 줍니다

가운데에서 가지가 사방으로 뻗고, 곡선으로 잇고, 색을 입히고 싶다면 이쪽입니다. 대신 이런 점이 따라옵니다.

- 노션 검색이 보드 안을 못 봅니다
- 그림 안의 내용은 노션 페이지와 연결되지 않습니다. "3분기 출시"라고 적은 상자와 "3분기 출시"라는 페이지는 서로를 모릅니다
- 노션 페이지를 공유받은 사람이 보드에도 접근할 수 있어야 합니다

## 어느 쪽을 쓸까

| | 토글 | 임베드한 보드 |
| --- | --- | --- |
| 시작까지 걸리는 시간 | 몇 초 | 몇 분 |
| 마인드맵처럼 보이나 | 아니요, 개요 모양 | 예 |
| 노션 검색에 잡히나 | 예 | 아니요 |
| 노션 페이지에 링크되나 | 예, `@` 로 | 주소를 붙여 넣는 것만 |
| 휴대폰에서 쓰기 | 잘 됨 | 도구에 따라 다름 |
| 맞는 쓰임 | 빠른 구조 잡기, 다시 쓸 노트 | 워크숍, 발표, 그리면서 생각하기 |

보드에서 브레인스토밍하고, 정리가 되면 그 결과를 토글이나 페이지로 다시 적는 방식이 흔합니다. 최종본이 검색되게 하려는 것입니다.

## 둘 다 공통인 한 가지

두 방법 모두 **지금부터 그릴 생각**을 위한 것입니다. 이미 써 둔 페이지 수백 개가 어떻게 엮여 있는지는 둘 다 보여 주지 못합니다. 그건 손으로 다시 옮겨 그려야 하고, 페이지를 하나 추가하면 그림은 그만큼 뒤처집니다.

이미 있는 페이지라면 그릴 필요가 없습니다. Notion-mind 는 데이터베이스 소속, 하위 페이지, 관계형 속성을 읽어 워크스페이스를 그대로 그래프로 펼칩니다. 두 가지 지도가 어떻게 다른지는 [노션에 마인드맵 기능이 있나요?](/ko/blog/notion-mind-map)에 더 적었습니다.
