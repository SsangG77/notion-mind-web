# 자주 묻는 질문

## 서비스에 대해

### Notion-mind는 무엇을 하는 도구인가요?

노션 워크스페이스의 페이지와 데이터베이스를 하나의 노드 그래프로 그려 줍니다. 어떤 페이지가 어느 데이터베이스에 속해 있고, 어떤 페이지끼리 관계형 속성으로 이어져 있는지를 선으로 보여줍니다. 노션의 사이드바 트리에서는 보이지 않는 "가로 연결"을 확인하는 용도입니다.

### 노션 공식 서비스인가요?

아닙니다. Notion-mind는 Notion Labs, Inc.와 무관한 독립 서비스입니다. Notion과 Notion 로고는 Notion Labs, Inc.의 상표이며, Notion-mind는 노션이 공개한 API를 이용해 만든 외부 도구입니다.

### 노션의 그래프 보기와 무엇이 다른가요?

노션 자체에는 워크스페이스 전체를 그래프로 보는 기능이 없습니다. 데이터베이스별로 표, 보드, 갤러리 같은 보기가 있을 뿐이고, 데이터베이스와 페이지를 넘나드는 연결 구조는 한 화면에 나오지 않습니다. Notion-mind는 그 빈자리를 채우는 시각화 전용 도구입니다.

### 옵시디언 그래프 뷰와 비슷한가요?

비슷한 발상입니다. 옵시디언은 노트 사이의 링크를 그래프로 그리고, Notion-mind는 노션의 소속 관계와 관계형 속성을 그래프로 그립니다. 마우스를 올리면 이웃만 선명하게 남는 포커스 방식도 옵시디언을 참고했습니다.

## 계정과 권한

### 회원가입이 필요한가요?

없습니다. 노션 계정으로 로그인하면 바로 사용합니다. 이메일이나 비밀번호를 따로 만들지 않습니다.

### 어떤 권한을 요구하나요?

읽기 권한만 요구합니다. 노션 인증 화면에서 허용한 페이지의 제목, 속성, 관계, 본문 일부를 읽습니다. 페이지를 수정하거나 만들거나 삭제하지 않습니다.

### 일부 페이지만 보여줄 수 있나요?

가능합니다. 노션 인증 화면에서 "페이지 선택"으로 허용할 페이지를 고르면, 그 페이지와 하위 페이지만 그래프에 나타납니다. 나중에 설정 패널의 "연결된 페이지 변경"에서 다시 고를 수 있습니다.

### 연결을 끊으려면 어떻게 하나요?

설정 패널에서 로그아웃하면 브라우저에 저장된 접근 토큰이 삭제됩니다. 노션 쪽에서 완전히 차단하려면 노션 설정 > 연결된 앱 에서 Notion-mind를 제거하세요.

### 팀 워크스페이스에서도 쓸 수 있나요?

가능합니다. 다만 인증한 사람이 볼 수 있는 페이지 범위 안에서만 그래프가 그려집니다. Pro 구독은 워크스페이스 단위로 적용되므로, 팀 워크스페이스에서 한 명이 구독하면 그 워크스페이스로 접속한 사람 모두에게 Pro가 적용됩니다.

## 그래프에 대해

### 페이지가 몇 개만 보입니다.

대개 인증 화면에서 일부 페이지만 허용한 경우입니다. 설정 패널의 "연결된 페이지 변경"에서 "모든 페이지"를 고르세요. Free 요금제는 최근 수정순 1,000개까지 표시하므로, 그보다 큰 워크스페이스는 우상단 페이지 수 박스에 상한 표시가 뜹니다.

### 방금 만든 페이지가 안 보입니다.

설정 패널의 "수동 동기화"를 누르세요. 노션 검색 API는 새 페이지를 몇 초 뒤에 반영합니다.

### 노드가 계속 움직입니다.

배치를 물리 시뮬레이션이 정하기 때문에 처음 몇 초간 출렁이다 정착합니다. 노드를 끌면 다시 움직이기 시작하고, 놓으면 다시 정착합니다. 특정 노드를 고정하고 싶으면 우클릭 > 핀 고정을 쓰세요.

### 점선은 무엇인가요?

데이터베이스의 관계형(relation) 속성으로 연결된 페이지 사이를 잇는 선입니다. 실선은 소속 관계(데이터베이스 안의 페이지, 페이지 안의 하위 페이지)입니다.

### 노드를 숨기면 노션에서 삭제되나요?

아닙니다. 숨기기는 그래프 화면에서만 치우는 것이고 노션에는 아무 영향이 없습니다. 하단 "숨긴 목록 보기"에서 언제든 되돌릴 수 있습니다.

### 큰 워크스페이스는 느린가요?

페이지를 100개 단위로 받아 그래프를 점진적으로 그리므로 처음부터 화면이 뜹니다. 수천 개 워크스페이스는 전체가 도착하기까지 수십 초가 걸릴 수 있고, 노션 API 요청 한도 때문에 더 빠르게 할 수는 없습니다.

## 요금과 결제

### 무료로 쓸 수 있나요?

네. Free 요금제는 페이지 1,000개까지, 그래프 기능 전부, 광고 표시 조건으로 무료입니다.

### Pro는 무엇이 다른가요?

페이지 수 제한이 사실상 없고(20,000개), 숨김과 핀 고정이 서버에 저장되어 다음 접속과 다른 기기에서도 유지되며, 광고가 사라집니다. 월 $7 또는 연 $48입니다.

### 결제는 어떻게 하나요?

요금제 화면에서 "Pro 구독하기"를 누르면 결제 대행사 Paddle의 결제창이 열립니다. 신용카드, 체크카드, PayPal 등 Paddle이 지원하는 수단으로 결제하며, 카드 정보는 Paddle이 직접 처리하고 Notion-mind는 저장하지 않습니다. 결제 통화는 미국 달러이고, 나라별 부가세는 결제창에서 별도 표시됩니다.

### 환불되나요?

결제일로부터 14일 이내에는 사유를 묻지 않고 전액 환불합니다. 자동 갱신 결제도 갱신일로부터 14일 이내면 같습니다. 자세한 내용은 [환불정책](/refund)을 보세요.

### 해지는 어떻게 하나요?

설정 패널 또는 요금제 화면의 "구독 관리"에서 Paddle 고객 포털로 이동해 해지합니다. 해지해도 현재 결제 기간이 끝날 때까지 Pro가 유지되고, 이후 추가 청구는 없습니다.

## 개인정보와 보안

### 내 노션 내용이 서버에 저장되나요?

아닙니다. 그래프에 필요한 제목, 속성, 관계 정보를 노션에서 읽어 브라우저로 전달할 뿐, 서버에 보관하지 않습니다. 서버에 남는 것은 Pro 구독 상태와(Pro의 경우) 숨김, 핀 설정뿐입니다. 자세한 내용은 [개인정보 처리방침](/privacy)에 있습니다.

### 접근 토큰은 어디에 있나요?

암호화되어 브라우저 쿠키에만 저장됩니다. 로그아웃하면 즉시 삭제되고, 로그아웃하지 않아도 30일 뒤 만료됩니다.

### 광고는 어떤 정보를 쓰나요?

Free 요금제에 표시되는 광고는 Google AdSense입니다. 첫 방문 시 쿠키 배너에서 동의하면 맞춤형 광고, 거부하면 일반 광고만 표시됩니다. 유럽 지역 접속자에게는 Google의 동의 관리 창이 추가로 표시됩니다.
